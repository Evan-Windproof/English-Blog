## What's Kernseed OS?

"Kernseed OS" is a small, educational operating system that I developed using Codex.

It has an independent kernel and is not a Linux distribution.

Currently completed and archived.

## What's has Kernseed OS achieved so far?

Limine boot, GDT/TSS/IDT and real exceptions, PIC/PIT, physical frames and controlled virtual mappings, preemptive kernel tasks, PS/2 keyboard and modular Shell, INT0x82 syscalls, minimal Ring3 and separately built embedded Hello/Counter apps.
